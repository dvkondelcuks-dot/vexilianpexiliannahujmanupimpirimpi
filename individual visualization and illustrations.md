# DOCUMENT 2

# Individual visualization and illustration specification

## Global visual principle

The site must not use decorative tech graphics.

Every visual must be a **commercial evidence object**.

A visual is valid only if it explains one of these:

1. where clients enter,
2. where they disappear,
3. which layer fixes the loss,
4. what the owner sees afterward,
5. how Vexilian operates.

---

## 00 · Hero visual

### Name

**Client Disappearance Map**

### Exact object

A large dark SVG map showing Latvian SME client movement.

The visual is split into four vertical zones:

1. **Sources**

   * Google Ads
   * Meta / IG
   * Organic
   * Direct
   * Referral

2. **Contact points**

   * Landing page
   * Form
   * Instagram DM
   * Call
   * Email

3. **Internal chaos**

   * Excel
   * WhatsApp
   * Memory
   * Unassigned
   * No follow-up

4. **Outcomes**

   * Booking
   * Purchase
   * Unknown
   * Lost
   * Report

### Originality upgrade

Do not make this a clean SaaS flow. Make the middle zone visibly messy.

The left side is ordered.
The right side is measurable.
The middle is where Latvian SME reality breaks: WhatsApp, Excel, DMs, calls, no owner.

That makes the visual specific and not generic.

### Styling

Background: dark graphite.
Flow lines: thin blue-grey.
Lost lines: amber, fading into smoke.
Successful lines: muted green.
Unknown nodes: outlined, not filled.
Internal chaos nodes: slightly misaligned, like unstructured objects.

### Relevance

The text says businesses do not know where clients disappear. This shows the exact disappearance zone.

### Name

**Three Operating Principles**

Three large panels with one custom diagram each.

Visual:

`CLICK → CONTACT → CRM → FOLLOW-UP → INVOICE → DASHBOARD`

Vexilian builds the whole route, not isolated assets.

Visual:

A loop:

`BUILD → LAUNCH → READ DATA → CALIBRATE → IMPROVE`

The loop should look mechanical, not playful.

Intent:

The system improves after handover.

### Panel 3: Boundary

Visual:

A gate component.

Rejected side:
`NO COMMERCIAL GOAL`

Accepted side:
`MEASURABLE OBJECTIVE`

Shows that Vexilian is selective.

### Styling

These panels must be calmer than the diagnosis section.
Use strong negative space.
No heavy animation.

### Relevance

The text defines belief, operating model, and boundaries. The visuals should feel like rules of engagement.

**Six-Layer Commercial Infrastructure Stack**

### Exact object

A vertical or diagonal stack of six dark infrastructure plates.

`UNKNOWN VISITOR`

`CONTACT POINT`

`STRUCTURED ROUTE`

After layer 03:
`LEAD RECORD`

`ATTRIBUTED LEAD`

`RECOVERABLE LEAD`

Plates should have depth, but not 3D gimmickry.

The section says six layers become one system. This visual shows the transformation of a messy signal into a measurable business object.
